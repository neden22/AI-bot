ACCOUNT CONNECTION

Walt / MCP

READ ONLY

Авторизуй ORBIT через Walt, щоб встановити MCP-з’єднання та отримати список інструментів. Дозвіл: лише perps.readonly. Торгові кнопки ORBIT продовжують працювати з паперовим рахунком.

Відкрити авторизацію Walt ↗

Натисни «Підключити Walt», потім відкрий авторизацію та підтвердь дозвіл у Walt. Після повернення натисни «Перевірити MCP».

Це підключення ще не завантажує баланс чи позиції та не виконує ордери. Список нижче — лише виявлені інструменти; виклик інструментів вимкнений.

Системна телеметрія

OS RUNTIME
HTTP / UI↕SQLite queue + OS Pipe↕Trading process

Процес ядра ізольований від HTTP і мовної моделі. Supervisor перезапускає завершені дочірні процеси; ліміт — 3 перезапуски за хвилину.

Протокол безпеки

RISK ENGINE

01 Ліміт втрати за UTC-добу: 3%

02 Максимум 3 позиції / ордери

03 Нові входи лише зі свіжою ціною ≤90 с

04 KILL зберігається після перезапуску

KILL скасовує очікувані ордери. Відкриті позиції залишаються під SL/TP; їх можна закрити в журналі.
